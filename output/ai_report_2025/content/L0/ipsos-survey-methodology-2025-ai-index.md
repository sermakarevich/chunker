# ipsos-survey-methodology-2025-ai-index

**Parent:** [[content/L1/airflow-etl-pipeline-data-classification-framework|airflow-etl-pipeline-data-classification-framework]] — A synthesized data engineering framework for Apache Airflow ETL pipelines integrates Tim's fixed cognitive profile, a single-file HTML request with an unpopulated requirements list, a dragon story AI prompt, corporate financial metrics (0.5 debt-to-equity ratio, 12% WACC, 25% tax rate), a runner-on-road kinetic scenario, and a global military unit intelligence request within a unified threshold evaluation architecture. The technical core details AI procurement classification using regex, BERTopic, and a pretrained DeBERTA transformer with a 20% relevance threshold; TED database processing via deeptranslator/Google Translator and NLP preprocessing (stop word removal, POS tagging, <NUM> substitution); and educational data sourcing through Code.org, CSTA, ECEP Alliance, IPEDS (CIP codes 11.01/11.02/11.07), OECD Data Explorer, and an omitted Ipsos survey methodology for the 2025 AI Index Chapter 8 public opinion data. The deliverable is strictly formatted as a JSON object containing the context, a fact-specific summary, and a lowercase hyphenated filename slug.

Regarding Chapter 8 on public opinion in the 2025 AI Index, the report utilized survey data from Ipsos but omitted the detailed methodology for the sake of brevity. More details about the Ipsos survey’s methodology can be found directly in the original survey itself.
